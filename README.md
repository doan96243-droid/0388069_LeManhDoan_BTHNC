# 0388069_LeManhDoan_BTHNC

Bài thực hành WinForms với các control nâng cao, sử dụng C# và .NET 8.

## Nội dung

- **Bài 1:** Quản lý sinh viên với `DataGridView` và `BindingSource`.
- **Bài 2:** Duyệt thư mục bằng `TreeView` và `ListView`.
- **Bài 3:** Mini Editor dùng hộp thoại mở/lưu tệp, định dạng văn bản và tìm/thay thế.
- **Bài 4:** Ứng dụng MDI kết hợp các form của những bài trước và đồng hồ.
- **AnhChup:** Ảnh minh họa kết quả thực hành.

## Chạy chương trình

Mở solution tương ứng (`Bai1.slnx` đến `Bai4.slnx`) bằng Visual Studio 2022 với workload **.NET desktop development**, sau đó chạy project.
